# Piano samples

`A0.mp3` … `C8.mp3` (30 files, one every minor third, 2.0 MB) are from the
**Salamander Grand Piano** (Yamaha C5) by **Alexander Holm**, licensed under
[Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/) (CC BY 3.0).

The files are the 44.1 kHz MP3 single-velocity-layer set distributed by the Tone.js project
(<https://tonejs.github.io/audio/salamander/>, source: <https://github.com/Tonejs/audio>). They are
unmodified. At runtime Maestro mixes them to mono, trims them to 3–5 s, pitch-shifts them to
neighbouring keys and shapes them with velocity filters and a damper release (`js/audio/audio.js`).
